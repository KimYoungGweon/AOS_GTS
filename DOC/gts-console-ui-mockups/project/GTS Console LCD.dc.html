LCD UI mockups — 800 × 480 (H mode) · 4.3″

문서의 5화면 구성을 그대로 옮겼습니다. 라벨은 영문 + 한글 보조, 선택 항목은 굵은 테두리로 표시하고, 화면 하단에는 고정 조그 바(선택 항목 / 현재값)를 두었습니다. AOS Manual 화면에만 제어 항목별 STEP 값을 함께 표시합니다.

Assumptions / 전제
  • 상단바 44px — 장비 연결 상태, Device 종류·ID 상시 표시
  • 하단 조그바 64px — 조그 대상과 현재값 표시 (jog / jog S/W는 외부 장치)
  • 터치 타겟 최소 44px (실험실 벤치, 맨손 기준)
  • UDP 218.147.152.41 : 5502 값 변경 시 즉시 전송
  • AOS 선택 시 기본 진입 화면은 Manual Mode (PAGE 4)
