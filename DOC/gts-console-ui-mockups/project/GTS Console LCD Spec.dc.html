void jog_rotate(int8_t dir) {
    ctrl_t *c = &ctrl[sel_idx];              /* HV, Frq, Duty, CV, LF_Frq, LF_Volt */
    c->value = clampf(c->value + dir * c->step[c->step_idx], c->min, c->max);
    lv_label_set_text_fmt(c->lbl_value, "%.*f", c->decimals, c->value);
    udp_send_param(c->param_id, c->value);   /* 값 변경 즉시 송신 */
}

9. UDP 프로토콜

상태: 준비 중 (미확정). 아래는 화면 동작에 필요한 전송 시점 정의이며, 패킷 포맷이 확정되면 본 절만 교체하면 됩니다.

시점방향필요 데이터
장치 선택 후 연결 확인콘솔 → 서버my_id, dev_type, dev_id
장치 변경 (연결 해제)콘솔 → 서버현재 dev_id 해제 요청 · 진행 중 동작은 정지 후 해제
연결 응답서버 → 콘솔link 상태, 장비 상태(IDLE / RUN), RTT
GFC Manual Pump On/Off콘솔 → 서버dev_id, pump_on
GFC Auto 시간 변경콘솔 → 서버start_sec, cycle_sec (0.1 단위)
GFC Auto Start / Stop콘솔 → 서버auto_run
AOS 측정 타입 선택 · Start / Stop콘솔 → 서버aos_type, run
AOS 측정 진행서버 → 콘솔elapsed, 총 샘플 수, 종료 플래그
AOS Manual 값 변경 (6종)콘솔 → 서버param_id, value
LF_Mode On/Off콘솔 → 서버lf_on
주기 상태 갱신서버 → 콘솔다음 분사까지 남은 시간

필요 시 참고용 초안: 0xAA | LEN | CMD | MY_ID | DEV_TYPE | DEV_ID | PAYLOAD(n) | CRC16 — 확정 포맷 주시면 표와 함께 정리해 드리겠습니다.
